# Onboarding — Первоначальная настройка

## Что происходит при первом запуске

Secure Browser Bot требует однократной регистрации владельца.
После этого только ты сможешь управлять ботом.

---

## Шаги

### Шаг 1 — Получи токен бота

1. Открой Telegram и найди [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`
3. Придумай название (например, `My Browser Bot`)
4. Придумай username (например, `my_browser_bot`)
5. Скопируй токен вида `1234567890:ABCDEFxxx...`

### Шаг 2 — Установи приложение

**macOS:**
1. Открой `SecureBrowserBot.dmg`
2. Перетащи `.app` в папку `/Applications`
3. Запусти приложение — появится иконка 🤖 в menu bar

**Windows:**
1. Запусти `SecureBrowserBot-Setup-*.exe`
2. Следуй инструкциям установщика
3. Заполни `BOT_TOKEN` в диалоге первого запуска

**Из исходников (разработка):**
```bash
cp .env.example .env
# Заполни BOT_TOKEN в .env
python src/main.py
```

### Шаг 3 — Зарегистрируйся как владелец

1. Найди своего бота в Telegram (по username из Шага 1)
2. Отправь команду:
   ```
   /register
   ```
3. Получи подтверждение:
   ```
   ✅ Регистрация завершена!
   Твой Telegram ID зарегистрирован как владелец.
   ```
4. Бот перезапустится в защищённом режиме

### Шаг 4 — Проверка

Отправь `/help` — должен прийти список всех команд.
Отправь `/status` — должно прийти сообщение со статусом бота.

---

## Что происходит после регистрации

- Конфиг сохраняется в системную папку с правами 600 (только ты читаешь)
  - macOS: `~/Library/Application Support/SecureBrowserBot/config.json`
  - Windows: `%APPDATA%\SecureBrowserBot\config.json`
- Любые попытки других Telegram-пользователей управлять ботом будут заблокированы
- Ты получишь уведомление о каждой попытке несанкционированного доступа

---

## Если что-то пошло не так

**Бот не отвечает:**
- Проверь что бот запущен: иконка 🤖 в menu bar (macOS) или процесс в диспетчере задач (Windows)
- Проверь `BOT_TOKEN` в конфиге

**Нужно сменить владельца (например, сменил Telegram-аккаунт):**
1. Остановить бота
2. Удалить или отредактировать `config.json`, убрав `ALLOWED_USER_ID`
3. Запустить снова — бот перейдёт в режим onboarding
4. Отправить `/register` с нового аккаунта

**Команда /register говорит "Владелец уже зарегистрирован":**
- Это защита от повторной регистрации
- Для смены владельца — см. пункт выше
