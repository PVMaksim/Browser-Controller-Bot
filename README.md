# Secure Browser Bot

Telegram-бот, который устанавливается на твой Mac или Windows-ПК и даёт полный удалённый контроль через Telegram — с iPhone, Android или любого устройства.

Управляй браузером, ищи и смотри видео, управляй компьютером — голосом или текстом.

---

## Возможности

### 🌐 Браузер
- Открыть любой сайт: `/open youtube.com`
- Поиск в интернете: `/search рецепт борща`
- Скриншот текущей страницы: `/shot`

### 📺 Медиапульт
- Поиск на RuTube, YouTube, VK Видео, Одноклассниках: `/find Интерстеллар`
- Управление воспроизведением через Telegram-кнопки: ▶️ ⏸ ⏪ ⏩ 🔊
- Автосохранение позиции — «Продолжить с 47:23» при следующем открытии
- Список «Посмотреть позже»: `/watchlist`

### 💻 Компьютер
- Усыпить Mac: `/sleep` · Заблокировать экран: `/lock`
- Системная громкость: `/vol_sys 50`
- Скопировать в буфер: `/copy текст`
- CPU/RAM/диск: `/sysinfo`

### 📷 OCR — текст на фото
Отправь фото — бот распознает текст и откроет поиск:
- Скриншот с названием фильма → поиск на платформе
- Фото книжной обложки, афиши, вывески → поиск

### 🎙 Голос
Все команды работают голосом. Просто запиши голосовое сообщение:
> «Найди фильм Дюна на рутубе» → открывает поиск
> «Поставь на паузу» → ставит на паузу
> «Усыпи мак» → усыпляет компьютер

## Установка

### macOS (рекомендуется)

1. Скачай последний `SecureBrowserBot.dmg` из [Releases](../../releases)
2. Открой `.dmg` и перетащи приложение в `/Applications`
3. Запусти — появится иконка 🤖 в menu bar
4. Отправь `/register` своему боту в Telegram

### Windows

1. Скачай `SecureBrowserBot-Setup-*.exe` из [Releases](../../releases)
2. Запусти установщик
3. Отправь `/register` своему боту в Telegram

### Из исходников (для разработчиков)

**Требования:** Python 3.11+, ffmpeg, Git

```bash
git clone https://github.com/user/secure-browser-bot
cd secure-browser-bot

# macOS
bash scripts/setup_macos.sh        # установит всё включая Xcode CLI Tools

# Windows
powershell -ExecutionPolicy Bypass -File scripts\setup_windows.ps1

# Или вручную (если setup не подходит):
python scripts/install_deps.py     # умная установка с fallback на бинарные колёса
playwright install chromium

# Конфиг
cp .env.example .env
nano .env  # вставь BOT_TOKEN

# Запуск
python src/main.py
```

> **Проблема с pydantic-core / greenlet?**  
> `python scripts/install_deps.py` сам пробует бинарные колёса — компилятор не нужен.

## Первый запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) → скопируй токен
2. Добавь токен в конфиг (`.env` или диалог первого запуска)
3. Запусти приложение
4. Напиши своему боту `/register` — ты станешь единственным владельцем

Подробнее: [docs/onboarding_flow.md](docs/onboarding_flow.md)

## Безопасность и надёжность

- Бот реагирует **только на тебя** — по Telegram ID
- При попытке доступа другого пользователя ты получишь уведомление
- Конфиг хранится локально с правами 600 (только ты читаешь)
- Никакой телеметрии, аналитики, автообновлений
- Браузер работает в изолированном профиле
- **Rate limiting**: не более 10 команд за 10 секунд — защита от случайных петель
- **Browser watchdog**: автоматически перезапускает браузер если он завис

## Переменные окружения

Все настройки описаны в `.env.example`:

| Переменная | Обязательная | Описание |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен бота от @BotFather |
| `ALLOWED_USER_ID` | — | Задаётся автоматически через `/register` |
| `BROWSER_TYPE` | — | `chromium` (по умолчанию) / `firefox` / `webkit` |
| `WHISPER_MODEL` | — | `base` (быстро) / `small` / `medium` (точнее) |
| `DEFAULT_MEDIA_PLATFORM` | — | `rutube` / `youtube` / `vk` / `ok` |

## Команды

| Команда | Действие |
|---|---|
| `/open <url>` | Открыть сайт |
| `/search <запрос>` | Поиск в интернете |
| `/shot` | Скриншот страницы |
| `/find [платформа] <запрос>` | Поиск видео |
| `/mediastat` | Статус плеера |
| `/watchlist` | Список «Посмотреть позже» |
| `/sleep` | Усыпить компьютер |
| `/lock` | Заблокировать экран |
| `/sysinfo` | CPU, RAM, диск |
| `/ocr` | Статус OCR и справка |
| `/status` | Статус бота (версия, браузер, watchdog, OCR) |
| `/help` | Все команды |
