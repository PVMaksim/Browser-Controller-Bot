  Secure Browser Bot v1.1.0 — Добро пожаловать!
════════════════════════════════════════════════════

Этот бот устанавливается на твой Windows-ПК и даёт
полный удалённый контроль через Telegram —
с iPhone, Android или любого устройства.

────────────────────────────────────────────────────
  ПЕРВЫЕ ШАГИ ПОСЛЕ УСТАНОВКИ
────────────────────────────────────────────────────

1. Создай бота у @BotFather в Telegram:
   • Напиши /newbot
   • Придумай название и username
   • Скопируй токен вида 1234567890:ABCDEFxxx...

2. При первом запуске приложение попросит ввести
   BOT_TOKEN — вставь токен из шага 1.

3. Напиши своему боту /register в Telegram —
   ты станешь единственным владельцем.

4. Готово! Управляй с телефона:
   /open youtube.com    — открыть сайт
   /shot                — скриншот
   /find Дюна           — найти видео
   /help                — все команды

────────────────────────────────────────────────────
  ТРЕБОВАНИЯ
────────────────────────────────────────────────────

- Windows 10 или новее
- Интернет-соединение (только для Telegram API)
- ffmpeg — установится автоматически через winget
